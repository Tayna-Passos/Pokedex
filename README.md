A **Pokédex Clássica** é uma aplicação web interativa e nostálgica desenvolvida com HTML, CSS e JavaScript puro, inspirada no design icônico da primeira Pokédex vermelha da região de Kanto. O projeto conecta-se diretamente à [PokéAPI](https://pokeapi.co/) para trazer a lista completa dos 151 Pokémon originais, unindo uma interface retrô fiel aos jogos clássicos com funcionalidades modernas de navegação e busca em tempo real.

---

## 🚀 Funcionalidades do Projeto

* **Catálogo Dinâmico:** Carrega e organiza os 151 Pokémon da primeira geração por ID e nome de forma automatizada.
* **Busca Instantânea:** Filtre rapidamente qualquer Pokémon digitando o nome ou o número na barra de pesquisa integrada.
* **Painel de Detalhes Completo:** Exibe a arte oficial do Pokémon, número de identificação, altura, peso, distintivos coloridos de tipo, barras visuais de estatísticas base (*stats*) e suas respectivas habilidades.
* **Controles Interativos Simulados:** 
  * Botões direcionais e botões de atalho integrados para navegar com facilidade pela lista.
  * Botão verde dedicado a limpar os filtros e resetar o catálogo para o estado inicial.
  * Botão azul para retornar rapidamente o foco e a rolagem da lista para o topo.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias:

* **HTML5:** Estruturação semântica da interface dobrável da Pokédex.
* **CSS3:** Estilização avançada com fontes retrô, paleta de cores temática, design flexível e responsivo.
* **JavaScript:** Lógica da aplicação, manipulação dinâmica do DOM, requisições assíncronas e gerenciamento de eventos de clique e teclado.
